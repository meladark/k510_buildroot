Места

Если система ошиблась — нажмите правильный вариант. Это сохранится как разметка вместе с фото для дообучения.

МестоКамераСтатусПерекрытиеСИсправить

Кликайте по углам парковочного места (обычно 4 точки), двойной клик или «Замкнуть контур» завершает место. Клик по готовому месту выделяет его; углы можно перетаскивать.

Скачать архив (.tar) Скачать разметку (labels.jsonl)

На плате: удерживать кнопку фото 1 секунду — запись, короткое нажатие — стоп. Каждая камера пишется в свой MP4 (H.264), запись сама останавливается через лимит из настроек.

    Сеть:

    Время — на один кадр одной камеры. Сравнение моделей на одном снимке: на плате остановить приложение (меню → любое другое) и выполнить /app/parking/parking --bench; результаты появятся здесь.
